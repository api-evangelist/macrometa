Macrometa is a global data network and edge computing platform. Its Global Data Network (GDN) provides a geo-distributed, serverless NoSQL database, pub/sub streams, complex event processing, and edge functions through a unified REST API plus first-party Python (pyC8) and JavaScript (jsC8) SDKs. Macrometa has since expanded into PhotonIQ, an AI-powered edge delivery suite for web performance and digital operations — prerendering, edge-side tagging, function-as-a-service, digital fingerprinting, virtual waiting rooms, event delivery, and hypersearch. This profile catalogs Macrometa's published OpenAPI surface across the GDN core and the PhotonIQ product family, along with its SDKs, CLI, status page, and developer documentation.

**Areas:** Company · Infrastructure · Edge Computing · Database · NoSQL · Serverless · Streaming · Stream Processing · Real-Time · Web Performance · CDN · Search

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Macrometa: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
